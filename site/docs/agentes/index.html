Para agentes

Un archivo Markdown con todo lo que tu agente necesita para instalar Skynex y empezar a usarlo. Lo instala de principio a fin, o lo actualiza si ya lo tenías.

Pásaselo a tu agente

Copia este mensaje en OpenCode, Claude Code, Codex o el agente que uses:

El agente comprueba los requisitos, instala o actualiza la CLI, instala Skynex de forma global con skynex install --global (o skynex update si ya estaba), comprueba la instalación con doctor y te resume lo que ha hecho. Cada paso deja una copia de seguridad.

El archivo

Esto es exactamente lo que leerá. Puedes abrirlo tal cual o copiarlo para pegarlo en tu agente.
